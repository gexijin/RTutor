**Requirements:** a Mac with Apple Silicon (M1 or newer) running macOS 12 Monterey or later, **or** a 64-bit Windows 10/11 PC. Intel Macs, Chromebooks and Linux are not supported.

### Download

| Your computer | File to download (under **Assets** below) |
|---|---|
| Mac (Apple Silicon) | `UIUC-RTutor-…-mac-arm64.dmg` |
| Windows | `UIUC-RTutor-…-win-x64.exe` |

### Install

The app isn't signed by Apple or Microsoft, so your computer will warn you the first time. This is expected.

- **Mac:** open the `.dmg` and drag **UIUC RTutor** into **Applications**. Open it once. When macOS says it can't verify the app, click **Done**, then go to **System Settings → Privacy & Security**, scroll down, and click **Open Anyway**.
- **Windows:** run the `.exe`. When "Windows protected your PC" appears, click **More info → Run anyway**.

**Full step-by-step guide with screenshots and troubleshooting:** [Install guide](https://github.com/gexijin/RTutor/blob/{{TAG}}/electron/INSTALL.md)

Already have an older version? Install this one over it. Older versions stop working when their semester ends.
